## What I do

I build iOS and Android apps from the first commit to the store release, mostly real-time chats, delivery services and apps that keep working offline.

- **Flutter / Dart:** one codebase for iOS and Android, shipped to Google Play, App Store, AppGallery and RuStore.
- **Real-time:** WebSocket chats, push notifications (FCM, Huawei Push Kit), audio and video calls (WebRTC / LiveKit, CallKit).
- **Offline-first:** a local SQLite database (Drift) synced with the server, so the app keeps working through restarts and bad networks.
- **Media:** camera, photo and video editing, voice messages, caching.
- **Architecture:** BLoC / Cubit and Riverpod, a repository layer, code generation (freezed, json_serializable), go_router.
- **Performance:** I measure on real low-end devices (frame times, database queue, cold start) and fix whatever the numbers point to.
- **Releases:** build flavors, signing, automated store uploads, CI on GitHub Actions.
- Outside Flutter, when the task needs it: native **Kotlin**, backend in **PHP** and **Python**.

## Projects

**Olkha** is a food delivery service with courier, customer and admin apps.

- **Courier app** (built from scratch): Riverpod + freezed, geolocation, maps, order notifications.
- **Customer app** (as part of the team): BLoC + hydrated_bloc, modular repositories, go_router, maps (flutter_map), real-time updates over WebSocket, FCM push.
